# Block Atlas

A visual learning environment for blockchain and distributed systems.

## Design principles

- Learn through a short guided scene, then change the experiment yourself.
- Use distinct visual models for distinct mechanisms: chains, trees, networks, clocks, logs, and proofs.
- Keep the primary interface concise; place assumptions and primary sources beside each lesson.
- Support English and Turkish throughout.
- Run entirely in the browser and build to portable static files.

## Research approach

The curriculum is grounded in original papers, protocol specifications, and official documentation. Algorithms, protocols, and system concepts are labeled separately. Educational models expose their assumptions instead of claiming production-level completeness.
